# Development notes

- Run `docker compose -f docker-compose.base44.yml up -d`. A single Node 22 development container runs the API on 3001 and Vite on 3000. The API is only exposed through Vite's same-origin `/api` proxy. The source is bind-mounted and both processes watch for changes.
- The startup command runs `npm ci` against the checked-in lockfile, with dependencies in a named volume. Do not install both processes concurrently into this volume.
- Node's built-in SQLite implementation requires Node 22 or later. Its experimental warning on Node 22 is expected. Schema creation is idempotent on startup; no migration or seed job is needed. Application records live in the `freight_data` volume at `/data/freight.sqlite`; never remove this volume to refresh source or dependencies.
- `ADMIN_PASSWORD` comes from `/run/base44/app.env`, not the repo. The generated development secret unblocks boot. The user must replace it in Secrets with their chosen strong password to sign in as `admin` at `/admin`. Never display this environment value. Use the secure dashboard instead of passing passwords in chat.
- All mutation requests require `X-App-Request: freight`; the shared frontend `api()` helper includes it. Auth uses random, hashed, expiring session tokens in SQLite and HTTP-only same-origin cookies. Quote, contact, and tracking routes are public; quote lists, contact lists, shipment changes, and company settings changes require admin authentication.
- Company details start blank or clearly labeled placeholders. Admin Company settings can configure Persian/English brand names, phone, address, email, WhatsApp digits, and social profile URLs. Call, WhatsApp, map, and social links should not pretend to be configured before real values exist.
- Persian RTL is the default; the language toggle persists locally. Keep layout rules logical (`inline-start`/`inline-end`) and provide Persian and English text for new content. The context is in `src/context.js` to preserve provider identity across component hot updates.
- Transport is road-only. No air or sea services. Route times are indicative, testimonials explicitly illustrative, and the user-supplied marketing figures require company confirmation before commercial use. Stock images are not photographs of the actual company fleet.
- Verify with `curl -f http://localhost:3000/`, `curl -f http://localhost:3000/api/posts`, and `docker compose -f docker-compose.base44.yml ps`. The Compose healthcheck checks both components independently. `docker compose -f docker-compose.base44.yml exec -T app npm run build` checks the frontend production build, but the preview must continue serving Vite source, not `dist`.
- Quote submission, language toggling, shipment lookup (success/not found), contact submission, and page rendering passed browser checks. Authenticated admin API creation/status updates and database persistence passed server checks. Temporary test records were removed. Authenticated admin UI gestures and mobile visual layout were not automatically verified; the platform's screenshot surface was hidden during setup.
